
# Caietul cu retete

1. Proiect Caietul cu retete  este realizat folosind tehnologiile: HTML, CSS si JavaScript.
2. API: https://dummyjson.com/recipes
3. GET /recipes preia lista retetelor.
4. POST /recipes/add simuleaza crearea unei retete.
5. Cererile folosesc fetch si verifica =>> response.ok.
6. Sunt tratate raspunsurile 200, 201, 4xx și 5xx.
7. Erorile 4xx sunt afisate langa formular.
8. Erorile de retea si lista goala au mesaje separate.
9. API-ul permite CORS; nu folosim proxy sau backend.
10. Site-ul este responsive si publicat pe GitHub Pages.

Important de stiut: Retetele adaugate nu sunt salvate permanent.
